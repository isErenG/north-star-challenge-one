# Go backend layout and Docker packaging

Decisions (2026-09-16): Go serves the built SvelteKit frontend and the API from
one image; `cmd/` + `internal/` layout by domain; job data stays as JSON files on
a Docker volume; target is local Docker only for now.

## Target repository layout

```
.
├── cmd/
│   └── kbo-review/
│       └── main.go            # wiring only: config → store → services → http server
├── internal/
│   ├── config/

│   ├── model/
│   │   └── model.go           # Record, Place, Job (JSON tags unchanged, so saved jobs and exports stay compatible)
│   ├── store/
│   │   ├── store.go           # Store interface: Get, Put, List
│   │   ├── file.go            # atomic JSON-file implementation, recovery of interrupted jobs on start
│   │   └── file_test.go
│   ├── parse/
│   │   ├── parse.go           # CSV / JSON / GeoJSON → []Record, column aliases, identifier handling
│   │   ├── csv.go
│   │   └── parse_test.go      # TestSchotenSchema, TestFormats, TestRejectsMalformedInput, TestRoundTripSourceAndGeometry
│   ├── validate/

│   │   └── validate_test.go   # TestNumberValidation, duplicate cases
│   ├── google/

│       ├── server.go          # NewHandler(deps) http.Handler; routes; respond/fail helpers
│       ├── handlers.go        # config, createJob, getJob, updateJob

├── docker-compose.yml

```

The current `server/` directory is removed once the packages above are in place.
`go.mod` moves to the repo root so `go build ./...` and `go test ./...` run from
the root and the Dockerfile has one build context.

## Package responsibilities and dependencies

Dependencies point inward only:

```
httpapi → jobs → {store, parse, validate, google, notify} → model
config is read once in cmd/kbo-review and passed as plain values.
```

- `model` has no imports from the module. It holds the three structs with their
  existing JSON tags.
- `store.Store` is an interface so `jobs` and `httpapi` tests use an in-memory
  or temp-dir store. `file.go` keeps today's behaviour: 0700 directory, write to
  temp file then rename, mark `processing` jobs failed and `sending`
  notifications `delivery unknown` on startup.
- `parse` and `validate` are pure functions over `[]model.Record`. They are the
  easiest to test and hold most of the existing test coverage.
- `google.Client` and `notify.Client` take an `*http.Client` so tests inject a
  fake transport, as `main_test.go` already does.
- `jobs.Service` owns the processing pipeline (parse → validate → optional
  Google lookup → notify) and the concurrency limit. It exposes methods the
  handlers call; it never touches `net/http` request or response types.
- `httpapi` is the only package that knows about HTTP. It also serves the
  frontend.

## Frontend changes

1. `svelte.config.js`: replace `@sveltejs/adapter-node` with
   `@sveltejs/adapter-static`, `pages: 'web'`, `assets: 'web'`,
   `fallback: 'index.html'`, `precompress: true`.
2. `src/routes/+layout.ts`: `export const prerender = true; export const ssr = true;`
   so `/` is prerendered to real HTML at build time.
3. Delete `src/routes/api/[...path]/+server.ts`. Its origin check and 10 MB cap
   move to `internal/httpapi/middleware.go`.
4. `vite.config.ts`: add `server.proxy = { '/api': 'http://127.0.0.1:8787' }`
   so `npm run dev` keeps working against the Go process.
5. `package.json`: `build` becomes `vite build` (unchanged); add
   `build:go` = `go build -o bin/kbo-review ./cmd/kbo-review`; `test` runs
   `go test -race ./...` from the root. Remove `@sveltejs/adapter-node`.

Nothing in `+page.svelte`, `MapView.svelte`, `export.ts` or `app.css` changes.

## Static serving in Go (`internal/httpapi/static.go`)

- `//go:embed all:web` in a small package-level variable, guarded by a build
  tag or a generated placeholder so `go test ./...` works before `vite build`
  (commit an empty `web/.gitkeep`; `all:` includes it).
- Route order: `/api/*` first; then exact file match from the embedded FS; then
  `index.html` fallback for any path without a file extension; 404 otherwise.
- Serve `.br` or `.gz` variants when the client accepts them (adapter-static's
  `precompress` generates both). Set `Content-Encoding` and `Vary: Accept-Encoding`.
- `Cache-Control: public, max-age=31536000, immutable` for `/_app/immutable/*`;
  `no-cache` for `index.html`.
- Security headers: `X-Content-Type-Options: nosniff`,
  `Referrer-Policy: no-referrer`, and a CSP that allows `api.mapbox.com`,
  `fonts.googleapis.com`, `fonts.gstatic.com`, `blob:` workers and `data:`
  images. Mapbox needs `worker-src blob:` and `child-src blob:`.

## Configuration

`internal/config` reads:

| Variable | Default | Notes |
|---|---|---|
| `ADDR` | `127.0.0.1:8787` | Compose sets `0.0.0.0:8787`; local runs stay on loopback. Replaces `API_PORT`. |
| `DATA_DIR` | `./data` | Compose mounts a named volume at `/data`. |
| `GOOGLE_MAPS_API_KEY` | empty | unchanged |
| `RESEND_API_KEY`, `NOTIFY_FROM`, `PUBLIC_APP_URL` | empty | unchanged |
| `MAPBOX_ACCESS_TOKEN` | empty | only `pk.` tokens are exposed |

`GO_API_URL` is no longer needed and is removed from `.env.example`.
A `GET /healthz` endpoint returns 200 once the store has loaded, for the
compose healthcheck.

## Dockerfile (multi-stage)

```
# 1. Frontend
FROM node:24-alpine AS web
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci
COPY . .
RUN npm run build            # writes web/ with precompressed assets

# 2. Go binary with the frontend embedded
FROM golang:1.24-alpine AS build
WORKDIR /src
COPY go.mod go.sum ./
RUN go mod download
COPY cmd ./cmd
COPY internal ./internal
COPY --from=web /app/web ./web
RUN CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o /out/kbo-review ./cmd/kbo-review

# 3. Runtime
FROM gcr.io/distroless/static-debian12:nonroot
COPY --from=build /out/kbo-review /kbo-review
ENV ADDR=0.0.0.0:8787 DATA_DIR=/data
VOLUME /data
EXPOSE 8787
USER nonroot
ENTRYPOINT ["/kbo-review"]
```

`.dockerignore` excludes `node_modules`, `.svelte-kit`, `web`, `build`,
`.context`, `server/data`, `.env*` (except `.env.example`), `test-results`,
`playwright-report`, `.git`.

Expected image size: about 25 MB (static binary plus embedded assets).

## docker-compose.yml

```
services:
  kbo-review:
    build: .
    ports:
      - "127.0.0.1:8787:8787"
    env_file: .env
    volumes:
      - kbo-data:/data
    healthcheck:
      test: ["CMD", "/kbo-review", "-check"]   # binary flag that GETs /healthz and exits 0/1; distroless has no curl
      interval: 30s
      timeout: 3s
      retries: 3
    restart: unless-stopped
volumes:
  kbo-data:
```

Ports bind to `127.0.0.1` on the host, matching the README's private-link
boundary.

## Migration order

Each step leaves the build and tests green.

1. **Move without changing behaviour.** Create `go.mod` at the root, add
   `cmd/kbo-review/main.go` that is today's `main.go` verbatim, delete
   `server/`. Update `scripts/dev.mjs` and `scripts/test.mjs` paths. Run
   `go test -race ./...`.
2. **Extract `model`, then `parse`, then `validate`.** Pure moves. Move the
   matching tests with them.
3. **Extract `store` behind an interface.** Add the in-memory test double.
4. **Extract `google` and `notify`** with injectable HTTP clients.
5. **Extract `jobs.Service`.** Handlers now call the service only.
6. **Extract `httpapi`** with middleware and `/healthz`. `main.go` is now
   wiring only, under 60 lines.
7. **Frontend to adapter-static**, delete the proxy route, add the Vite proxy,
   add `static.go`. Verify `npm run dev` and the built binary both serve the app.
8. **Dockerfile, compose, `.dockerignore`, README.** Build the image, run
   compose, upload `static/example.csv`, open the map, restart the container
   and confirm the job reloads from the volume.
9. **Playwright** against the container (`TEST_URL=http://127.0.0.1:8787`).

## Risks and notes

- Renaming `API_PORT` to `ADDR` is a small breaking change for anyone with an
  existing `.env`. The README and `.env.example` will say so.
- Embedding the frontend means `go build` needs `web/` present. CI and the
  Dockerfile run `npm run build` first. The committed `web/.gitkeep` keeps
  `go test` working without it.
- Removing SvelteKit's server proxy removes the 30 s upstream timeout. Go's
  existing `ReadTimeout`/`WriteTimeout` of 30 s cover it.
- The CSP is new. Mapbox, Google Fonts and blob workers must be allowed or the
  map breaks silently. Step 7 includes a browser check of the map.
